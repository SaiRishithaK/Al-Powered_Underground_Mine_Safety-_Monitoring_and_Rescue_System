# Person 2: AI Detection and Sensor Intelligence

This module provides a YOLOv8n video demo, simulated mine-environment readings,
hazard threshold evaluation, and a common JSON event report.

## Setup

Run these commands from the repository root in PowerShell:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r person2\requirements.txt
```

The detector uses the bundled sample video and downloads `yolov8n.pt`
automatically on the first run if the weights are not already available:

```powershell
python person2\ai\person_detector.py
```

To exercise the simulated hazard event path:

```powershell
python person2\ai\person_detector.py --sensor-scenario hazard-demo
```

The annotated video and JSON report are saved to `person2/results/`. The JSON
report contains simulated sensor readings, thresholds, summary counts, and
`survivor_detected` / `hazard_detected` events with the same event fields.

Run the sensor threshold tests with:

```powershell
python -m unittest discover -s person2\ai -p "test_*.py"
```

## Safety limitations

The sample video is synthetic. Sensor readings are generated by a simulator,
and thresholds are illustrative demo values, not regulatory limits. A visual
person detection does not establish that someone is alive or needs rescue.
Do not use this demo for operational mine-safety decisions.
